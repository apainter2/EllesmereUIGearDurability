# Changelog

All notable changes to this project are documented in this file.

## Archived - 2026-09-26

- Archived because EllesmereUI's built-in DataBars functionality can provide the same durability display.
- Use DataBars for new installations to avoid a separate companion implementation and duplicate readouts.

## 0.1.2 - 2026-09-25

- Confirmed compatibility with EllesmereUI 9.2.9.
- Updated the addon manifest and release documentation.

## 0.1.1 - 2026-09-20

- Confirmed compatibility with EllesmereUI 9.2.2.

## 0.1.0 - 2026-09-13

- Initial standalone Gear Durability companion release.
- Added an event-driven, independently movable durability display with per-slot tooltip details.
